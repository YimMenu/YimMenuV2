# التعريب العربي — YimMenuV2

فرع `arabic` من [YimMenuV2](https://github.com/YimMenu/YimMenuV2) مع واجهة عربية.

## ما تم تغييره

- إضافة طبقة ترجمة مركزية في `src/core/translation/`:
  - `Translation::Tr` يترجم النص الكامل.
  - `Translation::TrLabel` يترجم الجزء المرئي من عنوان عنصر ImGui ويحافظ على معرّف العنصر بعد `##`.
- ترجمة تسميات الأوامر ووصفها مرة واحدة عند إنشاء `Command`، مع إبقاء الأسماء الداخلية (`m_Name`) كما هي حتى تظل الاختصارات والإعدادات وسكربتات Lua متوافقة.
- ترجمة أسماء التبويبات والفئات والمجموعات وعناوين العناصر المشتركة (أزرار، تبويبات، قوائم منسدلة) وقت الرسم فقط.
- ترجمة النصوص المباشرة في تبويبات المرحلة الأولى: Self، Vehicle، Teleport، Network، Players، World، Settings.
- ترجمة نافذة التشغيل الأولى (Onboarding) بالكامل.
- إضافة نطاقات الحروف العربية وأشكال العرض إلى خطوط القائمة، مع Tahoma كخط احتياطي.

## كيف تعمل الترجمة

ImGui لا يدعم تشكيل الحروف العربية ولا اتجاه RTL. لذلك:

1. تُكتب الترجمات في `translations/ar.json` بالعربية الطبيعية (منطقية).
2. يقوم `tools/gen_translation_data.mjs` بتحويلها إلى **أشكال العرض العربية** (Arabic Presentation Forms-B) وإعادة ترتيبها بصريًا من اليسار إلى اليمين.
3. يُولَّد `src/core/translation/TranslationData.cpp` كجدول ثابت داخل الـ DLL، ويُبحث فيه وقت التشغيل.

أي نص غير موجود في الجدول يظهر بالإنجليزية تلقائيًا، لذلك لا تتعطل القائمة عند نقص ترجمة.

## البناء

البناء يتم عبر GitHub Actions:

1. ارفع التغييرات إلى فرع `arabic` في مستودعك.
2. افتح تبويب **Actions** ← **Arabic Build** ← **Run workflow** (أو انتظر تشغيله تلقائيًا بعد الدفع).
3. نزّل الـ Artifact: `YimMenuV2-arabic-<sha>` ويحتوي:
   - `YimMenuV2-arabic-<sha>.dll`
   - `YimMenuV2-arabic-<sha>.pdb`
   - `SHA256.txt`

البناء يستخدم نفس إعدادات البناء الرسمي: Clang + MSVC environment + Ninja + RelWithDebInfo.

## تحديث الترجمات

بعد تعديل `translations/ar.json`:

```powershell
cd tools
npm install
node gen_translation_data.mjs
node verify_translation_data.mjs
```

ثم ارفع `translations/ar.json` و`src/core/translation/TranslationData.cpp` معًا. لا حاجة لتشغيل Node في CI لأن الملف المولّد يُرفع مع المصدر.

## إضافة نصوص جديدة

- النصوص المباشرة في التبويبات: أضف المفتاح الإنجليزي إلى `ar.json` ثم غلّف الاستدعاء بـ:
  - `ImGui::Text("%s", Translation::Tr("...").c_str())`
  - `ImGui::Button(Translation::TrLabel("...").c_str())`
- تسميات الأوامر تُترجم تلقائيًا بمجرد إضافة مفتاحها إلى `ar.json`.

## حدود النسخة الحالية

- الواجهة تُعرض بمحاذاة يسارية (النص العربي صحيح لكن تخطيط ImGui أصلي LTR).
- تبويبا Recovery وDebug وبعض النصوص الديناميكية (أسماء المركبات، أسماء اللاعبين، أسماء السكربتات) ما زالت إنجليزية.
- الإشعارات ورسائل السجل ما زالت إنجليزية.
- النصوص المختلطة (عربي + أرقام/إنجليزي) قد تحتاج ضبطًا يدويًا في حالات نادرة.
